# Smartplanix

**Sua agenda inteligente** - Organize seus compromissos de forma simples e eficiente.

Smartplanix é um projeto onde clientes podem adicionar e visualizar seus compromissos

## Tecnologias utilizadas 

- Next.js 16
- TypeScript
- Tailwind CSS
- Shadcn/ui
- Lucide React

## Funcionalidades existentes

### Compromissos

- CRUD completo — Crie, edite, conclua e remova compromissos
- Visualização Diária — Grade de horários para o dia selecionado
- Visualização Semanal — Grade de horários com os 7 dias da semana
- Visualização Mensal — Grid com chips de eventos por dia
- Categorias — Organize por tipo (Trabalho, Pessoal, Estudos, Saúde, Família) com cores distintas
- Popover de detalhes — Clique em um evento para ver detalhes e editar
- Próximo compromisso — Card na sidebar mostrando o próximo evento futuro
- Horários — Defina data e hora do compromisso
- Repetição — Configure para repetir diária, semanal ou mensalmente
- Lembrete — Notificação push antes do compromisso
- Descrição — Adicione detalhes ao compromisso

### Tarefas

- To-do list simples e direto
- Marcar como concluída
- Edição inline do título
- Seção de concluídas colapsável
- Progresso — Acompanhe quantas tarefas foram concluídas

### Geral
- Mini calendário na sidebar para navegação rápida
- Tema claro e escuro
- Dados salvos localmente (localStorage)
